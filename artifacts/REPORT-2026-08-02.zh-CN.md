## 三、手机端全流程走查（真实 Chromium，390×844，触控模拟）

一名顾客在手机上从「自己找的图片」到「拼豆图纸」的完整链路，**每一步均实证**：

1. **开始页**：唯一主上传入口 +「打开已保存项目」「更多制作方式」次级入口；上传前无任何模式必答项（符合规范 §4.0/§18.6）；两个 file input 的 `accept` 分别正确限定 `image/png,image/jpeg,image/webp` 与 `.json`。
2. **上传 → 自动生成**：选择图片后自动进入预览并自动生成首个结果，**全程无「生成」按钮**（规范 §7.5）。摘要实时显示「48 × 36 颗 · 24 色 · 约 24 × 18 cm · 4 块拼板 · 共 1,728 颗」+「图纸统计校验通过」。
3. **四组普通设置**（sheet 内）：图案大小 / 颜色数量 / 效果风格 / 拼豆品牌齐全；选「小巧」后**自动重新生成**为 29 × 22 颗；「自定义」选中后才展开宽高输入；专业设置默认折叠，展开后内容完整（处理方式、格子取色、颜色接近方式、透明区域「低/推荐/高」、拼豆规格「常规 5 mm / 迷你 2.6 mm / 自定义」、拼板默认 29 × 29）。
4. **五种预览样式**（纯图案/带标注/色号图纸/圆角方格/圆环豆粒）同一行；从「原图」视图选样式自动切回「拼豆」视图；「拼豆/原图」分段 + 按住对比正常。
5. **一键去背景**：入口可用，进入「去背景选区」涂抹流程（本地模型存在，`capabilities.backgroundRemoval.available=true`）。
6. **编辑图纸**：画笔/橡皮/吸管/填充/选择齐全；撤销/重做图标按钮带中文 aria-label；水平/垂直翻转图案在 sheet 内；正面/查看反面；首次提示「单指绘制，双指移动和缩放」非阻塞可关闭。
7. **完成并导出**：四个顾客任务（分享图片/打印制作/材料清单/保存项目），移动端**无叠加 modal**；四种格式全部**实际下载成功**且文件名规范：

## 五、联网核对：功能与参数是否符合拼豆行业标准

| 项目 | 产品现状 | 行业标准（检索结论） | 判定 |
| ---- | ---- | ---- | ---- |
| 拼豆规格 | 常规 5 mm / 迷你 2.6 mm | Perler、Hama、Artkal、MARD 一致使用 5mm（midi）与 2.6mm（mini） | ✓ 符合 |
| 标准方板 | 默认 29 × 29，另有 14 × 14 小板 | 29×29 是单板事实标准（中外教程与主流商品一致），14×14 小板存在 | ✓ 符合 |
| 拼板数量计算 | ⌈列/板列⌉×⌈行/板行⌉，末板允许不满 | 多板拼接为标准做法 | ✓ 符合 |
| 色板 | MARD 221 色（A–M 系列）+ 默认 39 色 | MARD 221 色是中国拼豆社区**事实标准色板**，色号编码（A1、B8、H7 等）与实物色卡一致 | ✓ 符合 |
| 图纸尺寸预设 | 长边 29 / 48 / 72 颗 | 社区惯例：29 单板练手、48–72 多板进阶 | ✓ 符合 |
| 材料清单 | 色号 + 数量 CSV / 图例 | 同类工具（MeTool、pixelbead、makebead 等）核心交付物一致 | ✓ 符合 |
| 打印 PDF | 摘要页 + 每板一页 + 坐标图例 | 制作级文档为行业标准交付 | ✓ 符合 |

**与市场的差距（非规范缺陷，供决策参考）**：

1. 色板品牌仅 MARD + 默认 39 色；竞品普遍支持 COCO、Artkal、漫漫、盼盼、Perler、Hama 等多品牌（规范 §1.4 已将「多品牌色号转换」列入路线）。
2. MARD 另有 **291 色扩展版**，多款竞品支持；本产品固定 221 基础版（规范明确如此，进阶用户可能提出需求）。
3. 竞品有「套装档位（24/48/72/96/120/221 色）」快捷筛选；本产品用「手边有的颜色」自选，灵活度等效但缺少一键套装预设。
4. 「去杂色 / 孤立色点清理」「逐色制作 / 制作进度」在规范 §1.4 路线内，当前未实施（符合「不得以假按钮提前出现」的要求）。

## 七、用户体验总评（是否好用？）

**好用程度：中高。** 对目标用户「第一次把照片做成拼豆图纸的顾客」：

- ✅ 零学习成本入口：不用懂照片/像素画区别，不用先答任何设置。
- ✅ 结果优先：上传即得图纸，摘要数据（颗数、色数、成品尺寸、拼板数）可信且实时。
- ✅ 调整即改即得：四组通俗设置 + 自动重新生成，旧结果保留不清空。
- ✅ 专业深度可选：专业设置默认折叠但完整（处理方式、透明区域、拼豆规格、拼板）。
- ✅ 交付闭环：PNG 分享、PDF 打印、CSV 备料、JSON 存档，全部实测可用。
- ⚠️ 两个小摩擦：设置在 sheet 内的发现性（P3-5）；导出按钮文案不一致（P3-4）。

**结论：一名顾客在手机上使用自己找的图片素材，能够独立得到想要的拼豆图纸，且图纸符合真实拼豆材料标准（MARD 221 色号、5mm/2.6mm 豆径、29×29 拼板、用量清单）。**
