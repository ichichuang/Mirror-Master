# 6个造物社

6个造物社（仓库名保持 Mirror Master）是面向拼豆顾客的完整拼豆图纸设计工具，以结构化拼豆颜色矩阵为业务权威，支持照片、像素画和已有图纸三种模式。现有 OpenCV/Pillow 网格感知镜像能力保留为“已有图纸智能镜像”模块。

> [中文产品规范](docs/PRODUCT_SPEC.zh-CN.md) 是产品目标、算法、数据模型、体验和验收标准的唯一权威。其他文档仅提供实现或运维说明，不得定义竞争性产品规范。
>
> 部署完全不属于当前产品开发范围。开发只交付可验证的应用、本地运行时、构建产物和平台中立的[运维移交合同](docs/DEPLOYMENT.zh-CN.md)；owner 本地验收后由运维决定最终基础设施。

## 目标流程

1. 直接选择 PNG、JPEG 或 WebP 图片；也可从公开的小红书图文分享链接提取图片、打开已保存项目，或从“更多制作方式”进入“镜像已有图纸”。
2. 可选执行一次本地“一键去背景”，再裁剪/旋转，设置行列、拼豆与拼板参数，选择真实可用色板。
3. 生成确定性的拼豆颜色矩阵，并核对材料、实际尺寸和拼板布局。
4. 在 Canvas 中编辑、撤销/重做、切换正反面或执行矩阵镜像。
5. 导出 PNG、PDF、CSV 或项目 JSON。

已有图纸模式使用后端多证据全局格阵检测：清晰线网格、分离圆环/色块、横纵不同格距和
明确透视四边形会生成可切换候选；颜色只作为格位属性。确认后按完整 cell 重排，保持
权威区域外的标题、坐标、标签和图例不变；证据不足时要求用户提供完整范围、四角和实际
行列数，不输出伪造的高置信度结果。

## 重建目标架构

- Vite/TypeScript：移动端优先的上传、裁剪、生成工作区、Canvas 编辑器、palette/material inspector 和结果导出。
- FastAPI/OpenCV/Pillow：图片解码、确定性生成、严格项目校验、导出，以及保留的已有图纸网格检测/智能镜像。
- 结构化 palette source：生成前后端机器资产并验证默认 39 色与 MARD 221 色。
- 项目 `cells` 矩阵：预览、统计、材料、镜像和导出的唯一业务真相。

## 本地启动

要求 Python 3.12，以及 pnpm 或 Corepack。脚本会创建或复用 `backend/.venv`、安装依赖、构建前端，并在不启用 reload 的情况下启动统一服务：

```bash
./scripts/start-local.sh
```

应用地址：`http://127.0.0.1:8000`

健康检查：`http://127.0.0.1:8000/api/health`

仅开发前端时，Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。

本地源码默认不携带模型。首次本地启动前，由维护者显式获取并校验项目固定模型：

```bash
backend/.venv/bin/python scripts/fetch-background-removal-model.py
```

模型缺失或初始化失败时，`/api/capabilities` 会报告该能力不可用；前端保留禁用入口并显示错误状态，避免静默丢失功能。模型权重仍被排除在 Git 和 Docker build context 之外；容器构建会在独立阶段从 manifest 固定来源下载，并在大小与 SHA-256 校验通过后复制进最终运行镜像。下载或校验失败会直接终止构建。

## 容器移交材料

```bash
docker compose up -d --build
```

该命令只用于验收仓库保留的 `Dockerfile` 与 `compose.yaml`。首次构建需要访问 manifest 固定的模型来源；构建成功后，`/api/capabilities` 必须报告 `backgroundRemoval.available: true`。容器通过 `0.0.0.0:8000` 提供统一前后端服务，宿主机映射端口为 `8000`；生产网络和发布方式由运维在最终移交后决定。

## 隐私

本地上传的图片会进入用户控制的 6个造物社服务，在内存中完成解码、一次性本地 CPU 去背景、识别、镜像和 PNG 编码，不写入持久存储，也不发送给第三方图片服务。使用“小红书提取图片”时，服务会访问用户粘贴链接对应的小红书公开页面和图片 CDN；分享文本只用于本次提取，会话 URL 仅在单进程内存中保留 10 分钟，图片字节不缓存、不写入持久目录。

小红书提取仅支持无需登录即可访问的公开图文笔记，不支持视频、实况照片的视频部分、私密或删除笔记、Cookie、验证码或风控绕过，也不会对作者原图中内嵌的水印执行像素擦除。失败时请先在小红书保存图片，再使用本地上传入口。用户只能处理本人拥有或已获得授权的内容。

服务不记录文件名、图片字节、哈希、边界合同或完整分享链接，并为响应设置 `Cache-Control: no-store`。运维最终运行时必须使用 HTTPS，并确认反向代理、访问日志和监控不会记录请求体。
