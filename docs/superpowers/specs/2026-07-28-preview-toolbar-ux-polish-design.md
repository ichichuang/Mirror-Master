# 预览工具栏与画布优先体验优化设计

- 日期：2026-07-28
- 状态：已实施并验证
- 范围：预览工作区工具栏、模式切换反馈和状态展示

## 1. 目标

本轮只优化预览阶段的界面密度与交互反馈：

1. 在移动端减少顶部控件占用，让拼豆画布获得更多首屏空间。
2. 保留“拼豆 / 原图”作为始终可见的核心对比入口。
3. 让裁剪、去背景和换图保持容易发现，同时不再用长篇说明挤压画布。
4. 确保用户在原图状态点击预览模式时立即看到对应结果。
5. 保持现有矩阵、统计、生成、导出、镜像和项目格式合同不变。

## 2. 选定方案

采用“画布优先的紧凑双层工具栏”：

- 第一层是对比与图片操作。
- 第二层是五种拼豆预览模式。
- 画布、项目摘要与底部设置面板保持原有层级。

不采用集中式图片操作菜单，因为会降低去背景和换图的可发现性；不采用单纯调整间距，因为无法解决原图状态下模式切换无反馈的问题。

## 3. 第一层：对比与图片操作

第一层固定包含：

- “拼豆 / 原图”分段控件。
- “裁剪”按钮，对应现有“调整原图”行为。
- “去背”按钮，对应现有一键去背景、恢复原图或使用缓存去背景图的状态。
- “换图”按钮，对应现有更换图片行为。
- 桌面端继续提供“按住对比”。

移动端使用短文案“裁剪 / 去背 / 换图”；桌面端可显示“调整原图 / 一键去背景 / 更换图片”。所有按钮至少 44 × 44 CSS px，并保留明确的 `aria-label`。

“原图”选项不得因加载、生成、去背景能力、源图状态或断点而隐藏。去背景能力不可用时只隐藏“去背”按钮，不改变其他控件位置与语义。

## 4. 第二层：预览模式

保留五种模式及现有顺序：

1. 纯图案
2. 带标注
3. 色号图纸
4. 圆角方格
5. 圆环豆粒

模式切换继续只重绘当前矩阵，不触发生成请求，不改变 project revision、统计、历史或导出选择。

新增交互合同：

- 用户处于“原图”或“调整原图”状态时点击任一预览模式，系统立即切回“拼豆”并应用该模式。
- 当前模式通过 `aria-pressed`、主色边框和浅主色背景表达。
- 每次切换通过现有稳定状态区宣告“已切换为{模式名称}预览”。
- 390 px 宽度下五种模式完整显示；320 px 下只允许模式条内部横向滚动，不允许页面横向溢出。

## 5. 去背景状态与文案

移除常驻长说明“自动保留主要人物或物体，处理后可恢复原图”。

默认状态不显示额外说明。只有以下状态显示一行紧凑反馈：

- 处理中：正在去除背景…
- 首次成功：已去除背景，可随时恢复原图。
- 恢复原图：已恢复原图，可再次使用去背景图。
- 使用缓存结果：已切换到去背景图，可随时恢复原图。
- 失败：无法完成一键去背景。原图和当前图纸已保留，请稍后重试。

状态使用现有 `role="status"` 和 `aria-live="polite"`，不增加 toast、modal 或新的持久面板。

## 6. 画布与加载反馈

- 新生成开始时继续保留上一份有效拼豆结果。
- 进行中状态显示在画布内部顶部，不改变画布几何、不遮挡主要图案、不推动页面布局。
- 首次结果尚未就绪时仍显示现有空状态。
- 生成完成或失败后，画布内部状态自动消失，详细结果继续由现有稳定状态区宣告。
- 原图与拼豆 Canvas 继续使用同一绝对定位几何合同。

## 7. 响应式布局

### 320–767 px

- 第一层使用一行紧凑布局：分段控件优先占据稳定宽度，图片操作使用短文案。
- 去背景状态独占下一行，但只在有实际状态时占用空间。
- 第二层不换行，390 px 完整显示，320 px 内部滚动。
- 目标是在 390 × 844 视口相对当前版本释放至少 40 px 画布或可见内容高度。

### 768–1023 px

- 对比、图片操作和模式条完整显示，不依赖移动端底部面板遮挡。

### 1024 px 及以上

- 使用完整动作文案。
- 保留“按住对比”。
- 工具栏与右侧 inspector 顶部对齐，不增加新的面板或卡片。

## 8. 视觉规则

- 延续现有 mint studio 色板、边框、阴影和圆角。
- 不新增图片资产、渐变、玻璃效果、徽章或装饰动画。
- 图片操作按钮属于同一组件家族，尺寸、边框和选中反馈一致。
- 模式栏是本页面唯一持续选中控件，不增加第二种高饱和强调。
- 画布仍是首屏视觉主体。

## 9. 技术边界

- 不修改 `BeadProject` schema。
- 不修改生成、去背景或导出 API。
- 不修改材料统计、历史、镜像或编辑器。
- 复用现有 Vaadin 分段控件、原生按钮、稳定状态区和 CSS token。
- 不增加依赖或全局状态。

## 10. 验收条件

- 原图选项在 320、390、768 和 1440 px 始终存在且可操作。
- 390 px 第一层无换行错位，五种模式完整显示。
- 320 px 页面横向溢出为 0；模式条可内部滚动。
- 从原图或调整状态点击任一模式会切回拼豆，并显示正确选中状态。
- 去背景默认不显示长说明；进行中、成功、恢复和失败状态均有稳定中文反馈。
- 旧预览在重新生成期间保持可见，画布尺寸不发生跳变。
- 所有图片操作命中区域至少 44 × 44 CSS px。
- 前端测试、类型检查、Lint、构建和 Browser/IAB 移动端与桌面端验证通过。

## 11. 实施与验收证据

2026-07-28 使用 Browser/IAB 在 `http://localhost:5173/` 上传真实 fixture
`backend/tests/fixtures/owner-grid.jpg` 完成验收：

- 390 × 844：对比控件和裁剪、去背、换图保持同一视觉行；三项操作均为
  46.96 × 44.35 px；五种模式完整显示，模式条 `clientWidth` 与 `scrollWidth`
  同为 358 px；空去背景状态为 `display: none` 且高度为 0。
- 320 × 720：页面横向溢出为 0；三项操作均为 44 × 44.35 px；模式条为唯一
  横向滚动区，`clientWidth` 288 px、`scrollWidth` 319 px。
- 1440 × 900：使用完整动作文案，三项操作与“按住对比”保持同排；页面横向
  溢出为 0，模式条不滚动。
- 390 px 原图和拼豆 Canvas 均为 `x=17, y=234.76, 356 × 379`；1440 px
  均为 `x=304.90, y=242.34, 499 × 533`，两种视口逐项完全相等。
- 从“原图”选择“色号图纸”后，原图隐藏、拼豆显示、“拼豆”重新选中且
  “色号图纸”的 `aria-pressed` 为 `true`；进入“调整原图”并点击“完成调整”
  后正确回到对齐原图。
- 与实施前 `/tmp/bean-preview-mobile-final.png` 对比，390 px Canvas 顶边从
  截图约 341 px 提前到 234 px，释放约 107 px 首屏可见内容空间；Canvas 高度
  仍为 379 px，没有以缩小图案换取空间。

视觉复核覆盖：

1. 文案：常驻长去背景说明已移除，移动端改为“裁剪 / 去背 / 换图”。
2. 布局：图片操作归为同一组件组，预览模式保持独立第二层。
3. 字体与层级：动作、模式说明和项目摘要继续使用现有字号层级。
4. 颜色：沿用 mint token；没有新增高饱和色、渐变或玻璃效果。
5. 容器与间距：画布继续是主视觉，空状态不占高度，右侧 inspector 未改变。
6. Canvas chrome：边框、圆角、背景与严格对齐几何保持不变。
7. 响应式：390 px 全量显示，320 px 仅模式条内部滚动，1440 px 使用完整文案。

批准的参考图强调大画布、清晰模式入口、固定底部工作面板和 mint 主操作；本轮
保持这些层级。参考图属于编辑/材料阶段，当前页面属于预览阶段，因此没有复制其深色
主题、左侧工具轨或材料列表，这是有意的阶段差异。
