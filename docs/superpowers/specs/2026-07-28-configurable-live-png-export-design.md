# 可配置实时 PNG 导出设计

## 目标

把“分享图片”从固定模板选择升级为所见即所得的 PNG 图片导出：

- 预览页已有的 5 种样式都可以导出。
- 用户可以在预设基础上自由组合背景、网格、坐标、色号、统计和材料信息。
- 配置变化后立即显示最终导出效果，不需要额外点击“预览”。
- 屏幕预览与下载图片由同一个渲染器和同一份项目快照生成。
- 本次范围只包含 PNG 图片导出；PDF、CSV 和项目文件保持现有行为。

## 顾客流程

1. 顾客在编辑器中点击“完成并导出”。
2. 默认进入“分享图片”，并自动选择最近一次预览样式对应的导出预设。
3. 顾客可以：
   - 选择 5 个样式预设之一；
   - 修改背景和豆粒外观；
   - 单独开关 6 项内容；
   - 始终在主预览区域看到最终 PNG 的完整构图。
4. 任意配置被修改后，预设状态显示为“自定义”；如果配置重新匹配某个预设，则恢复该预设名称。
5. 点击“下载图片”时直接下载当前有效预览对应的 PNG。
6. 关闭导出面板后恢复进入导出前的编辑器视图、滚动位置和焦点。

## 响应式交互

### 桌面端和平板端

- 导出配置继续使用现有右侧检查器。
- 左侧主画布切换为完整的最终 PNG 预览，不显示编辑工具覆盖层。
- 预览按最终图片比例完整适配可用空间。
- 下载按钮固定在右侧面板底部，配置内容独立滚动。

### 手机端

- 导出界面使用现有全屏面板结构。
- 顶部保留约 35%–42% 可视高度显示最终 PNG 预览。
- 配置区域在预览下方滚动。
- 下载按钮固定在安全区上方。
- 透明背景使用棋盘格承托，避免被误认为白色背景。

## 配置合同

```ts
type PngExportPreset = 'pure' | 'annotated' | 'numbered' | 'rounded' | 'ring';

type PngExportPresetMatch = PngExportPreset | 'custom';

type PngExportBackground = 'transparent' | 'white';

type PngExportAppearance = 'bead' | 'solidSquare' | 'roundedSquare' | 'ring';

interface PngExportConfiguration {
  readonly background: PngExportBackground;
  readonly appearance: PngExportAppearance;
  readonly includeGrid: boolean;
  readonly includeCoordinates: boolean;
  readonly includeCellCodes: boolean;
  readonly includeStatistics: boolean;
  readonly includeMaterialCounts: boolean;
  readonly includeColorLegend: boolean;
}
```

界面通过 `resolvePngExportPreset(configuration)` 派生当前预设或“自定义”状态。预设不写入渲染配置，避免预设名称和实际内容不一致。

| 预设     | 背景 | 外观     | 网格 | 坐标 | 格内色号 | 统计 | 材料数量 | 色块图例 |
| -------- | ---- | -------- | ---- | ---- | -------- | ---- | -------- | -------- |
| 纯图案   | 透明 | 标准拼豆 | 关   | 关   | 关       | 关   | 关       | 关       |

预设只负责一次性写入配置。之后每项都可以修改，不会被预设锁定。

## 控件结构

“分享图片”下使用以下顺序：

1. **实时预览状态**
   - 显示当前预设名称或“自定义”；
   - 显示正在更新、已就绪或错误状态；
   - 不提供单独的“导出预览”按钮。
2. **选择样式**
   - 纯图案；
   - 带标注；
   - 色号图纸；
   - 圆角方格；
   - 圆环豆粒。
3. **背景**
   - 透明；
   - 白色。
4. **豆粒外观**
   - 标准拼豆；
   - 实心方格；
   - 圆角方格；
   - 圆环豆粒。
5. **导出内容**
   - 网格线；
   - 行列坐标；
   - 格内色号；
   - 图纸统计；
   - 材料数量；
   - 颜色色块图例。
6. **内容摘要**
   - 用一句话说明当前图片包含的内容；
   - 例如：“白色背景 · 圆环豆粒 · 网格与坐标 · 统计和色块图例”。
7. **下载图片**
   - 仅在当前项目快照与预览结果一致时可用。

所有控件沿用现有颜色、圆角、间距、焦点状态和 Vaadin 表单组件，不引入新的视觉系统。

## 实时渲染架构

### 单一渲染来源

新增前端 PNG 导出渲染器。它接收不可变的项目快照和 `PngExportConfiguration`，输出：

- 最终尺寸和布局计划；
- 可供界面展示的画布；
- 可直接下载的 PNG `Blob`。

实时预览和下载必须复用同一次有效渲染结果。下载时不再重新解释配置，也不调用另一套 PNG 模板逻辑。

### 渲染层次

1. 计算图案、坐标区、统计区和材料图例区尺寸。
2. 绘制背景。
3. 根据 `appearance` 绘制豆粒或色格。
4. 按需绘制网格、五格/十格辅助线、坐标和格内色号。
5. 按需绘制统计摘要。
6. 按需绘制材料数量和颜色色块图例。
7. 生成最终 PNG `Blob`。

没有启用统计、材料或图例时，不保留对应空白区域。

### 更新调度

- 每次配置变化只安排一次下一帧渲染。
- 同一帧内的连续修改会被合并。
- 新的项目 revision 或配置版本会使旧任务失效。
- 只有最新版本可以更新预览、下载按钮和状态信息。
- 渲染期间保留上一张有效预览，避免界面闪白。

### 大图与色号可读性

- 格内色号启用时，单格尺寸必须达到可读下限。
- 渲染器在浏览器画布边长和总像素限制内计算最大可用比例。
- 如果图纸规模导致色号无法在安全资源范围内保持可读，不静默隐藏色号；显示明确错误并禁用下载。
- 透明背景的预览容器使用棋盘格，PNG 像素仍保持真实透明。

## 与现有导出流程的关系

- “分享图片”改用前端本地 PNG 渲染结果。
- “打印制作”继续请求现有 PDF 导出。
- “材料清单”继续使用现有 CSV 在线/离线回退。
- “保存项目”继续使用本地 JSON 导出。
- 现有后端 PNG 模板接口保留，避免破坏 API 合同，但顾客界面的 PNG 下载不再依赖它。
- PNG 样式可用性由本地渲染器决定，不再被后端 `pngTemplates` 能力列表限制。

## 状态与错误

- `idle`：尚未渲染。
- `rendering`：正在合并配置并更新预览。
- `ready`：预览和下载 Blob 来自同一项目 revision 与配置版本。
- `error`：显示稳定中文错误，保留上一张有效预览但禁用下载。

错误至少覆盖：

- 当前没有图纸；
- 项目 revision 已变化；
- 浏览器无法创建所需画布；
- 画布像素超出安全范围；
- 字体或 PNG 编码失败；
- Blob 生成期间配置再次变化。

## 可访问性

- 样式、背景和外观使用有明确组名的单选控件。
- 内容选项使用原生语义复选框或 Vaadin Checkbox。
- 实时状态使用 `role="status"` 和 `aria-live="polite"`。
- 渲染期间不抢夺焦点。
- 手机端预览和配置顺序与视觉顺序一致。
- 所有触控目标不小于现有 44px 标准。

## 测试设计

### 状态与配置

- 5 个预设映射到准确配置。
- 任意字段变化后派生为“自定义”。
- 配置重新匹配预设后恢复预设名称。
- 打开导出页时正确同步最后一次预览样式。
- 非 PNG 任务不保留 PNG 配置控件焦点或错误状态。

### 布局与渲染

- 透明背景具有真实 alpha。
- 4 种豆粒外观均可渲染。
- 网格、坐标、色号、统计、材料数量和色块图例可独立开关。
- 未启用的内容不占用最终画布空间。
- 色号在支持范围内始终可读，不因预览缩放而消失。
- 统计和材料数量来自同一项目快照。

### 并发与下载

- 快速连续修改只接受最后一次渲染。
- 项目 revision 变化会使旧 Blob 失效。
- 下载 Blob 与当前预览共享同一配置版本。
- PNG 在离线状态下仍可生成。

### 浏览器验证

- 桌面端左侧实时预览、右侧配置和吸底下载。
- 手机端顶部实时预览、可滚动配置和安全区下载按钮。
- 逐项切换 5 个预设与 7 项配置时没有跳动、遮挡或过期画面。
- 下载图片的尺寸、透明度、色号、统计和图例与实时预览一致。

## 不在本次范围

- 自定义 PDF 页面内容。
- CSV 字段配置。
- 项目文件内容裁剪。
- JPG、WebP 或 SVG 导出。
- 保存自定义配置为新的命名模板。
- 云端同步导出偏好。
